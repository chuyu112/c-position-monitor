# C 位标注与配置格式

## 逐帧标注

使用 UTF-8 JSON Lines，每行对应一帧，帧号从 0 连续递增，禁止空行。标注坐标是 profile 指定画布中的像素坐标。

```json
{"frame": 0, "members": ["AIJING"], "boxes": [[270, 330, 416, 1121]]}
```

`members` 与 `boxes` 必须一一对应，每帧最多两人；无 C 时两者均为空数组。每个框为 `[x1, y1, x2, y2]`，满足 `0 <= x1 < x2 < width` 和 `0 <= y1 < y2 < height`。坐标允许有限浮点数。可保留 `observations`、`review_note` 等追溯字段，计时只读取正式框与成员。

可选 `seconds` 字段必须与 `frame / fps` 的差不超过 0.001 秒。检测缓存中的 `selected_ids` 和 `people` 是候选数据，不能直接作为姓名标注输入；需先人工确认成员并生成上述格式。

## 场景配置

`--profile portrait` 和 `--profile landscape` 读取随包配置，也可传入任意自定义 JSON 文件路径。标注路径相对配置文件所在目录解析。

```json
{
  "schema_version": 1,
  "name": "portrait",
  "annotations": "../reviewed/portrait.jsonl",
  "fps": 30,
  "frame_count": 6824,
  "annotation_size": [720, 1280],
  "output_size": [720, 1280],
  "source_trim_seconds": 0,
  "source_crop_xywh": null,
  "music_start_frame": 0,
  "members": ["AIJING", "XILI", "OA", "MERCI", "AYUNE", "YOUNG", "VORA", "RADA", "HIMEKI"],
  "chinese_names": {"AIJING": "盛艾敬", "XILI": "梁淅沥", "MERCI": "马西桐"},
  "flags": {"AIJING": ["CN"], "OA": ["US", "JP"]}
}
```

`name` 为 `portrait` 时采用竖屏排行榜布局，其他值采用横屏布局。`output_size` 是未缩放的输出画面尺寸；指定空间裁切时应与裁切宽高相等。`music_start_frame` 之前必须空框。

随包配置还包含 `annotations_sha256`、`expected_member_frames` 和 `expected_c_count_frames`，用于最终基线核对。自己建立新配置时可以提供这些值锁定复核结果；编辑标注时使用 `--annotations` 覆盖路径，并以 `--no-baseline` 跳过旧数值比对。所有数据仍须符合当前配置的帧数、尺寸与音乐起点。

## 输出时间范围

计时区间采用 `[start_frame, end_frame_exclusive)`。30 FPS 下 `[4071, 4085)` 为 14 帧，从 135.7 秒开始，结束于约 136.167 秒。

报告总是覆盖完整输入标注。若导出短片，`summary.json.render` 另存实际导出的起始帧、结束帧、尺寸和是否存在源音轨，`counter_origin_frame` 固定为 0。
