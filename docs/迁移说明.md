# C 位代码迁移说明

2026 年 10 月 26 日，从原工作目录整理出本独立仓库。原视频、原输出和其他项目保留原位置，后续开发入口为 `c_monitor` 和 `c_detect`。

| 原文件或目录 | 新位置 | 用途 |
| --- | --- | --- |
| `c_detect/` | `c_detect/` | 原候选算法和命令行，保留行为 |
| `outputs/c5-red-name-aijing-himeki/corrected_boxes.jsonl` | `c_monitor/data/reviewed/portrait.jsonl` | 竖屏最终基线 |
| `outputs/neon-screen-recording-v8/corrected_boxes.jsonl` | `c_monitor/data/reviewed/landscape.jsonl` | 横屏最终基线 |
| 竖屏与横屏各自硬编码参数 | `c_monitor/data/profiles/` | 独立场景配置 |
| 分散的实时排行榜与计时实现 | `c_monitor/timing.py` | 共享整数帧计时及稳定排序 |
| 不同版本的视频导出入口 | `c_monitor/media.py` 与 `drawing.py` | 共享素材检查、叠加与导出 |
| 舞蹈相关历史脚本 | `legacy/scripts/` | 追溯角色迁移、空间修正和旧版验证 |
| 最终角色及姓名修正规则 | `legacy/` | 人工规则与最新局部修订记录 |

两个最终标注文件按原字节复制，SHA256 和帧数记录在 [migration_manifest.json](migration_manifest.json) 中。45 个历史脚本保留来源哈希及打包哈希，个人 home 绝对路径统一替换为 `/path/to/user`。它们依赖原工作目录内的历史产物，仅用于追溯；可移植运行使用 README 的共享入口。

新计时器延续每个可见框每帧加一、双 C 分别累计、同分稳定排序的规则。共享导出使用统一的国旗姓名牌和两种比例的排行榜布局，视频编码改用跨平台 H.264/AAC。历史成片的具体排版、HEVC 编码和截图验收记录属于对应旧版本；完整历史重建仍需原素材及其输出目录。

仓库未纳入视频成品、原始视频、模型权重、虚拟环境、小红书评论数据、演唱评分原型或录屏工具。相应运行目录和媒体扩展名由 `.gitignore` 排除。
